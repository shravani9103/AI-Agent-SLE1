# AI-Agent-SLE1

## Basic AI Agent Project

This project is developed for the **AI-Augmented Workflow** course.

The project demonstrates a simple rule-based AI Agent developed using Python. The agent accepts user input, identifies predefined keywords, and provides an appropriate response.

## Objectives

- Understand the basic concept of an AI Agent.
- Implement a simple decision-making system using Python.
- Use Git and GitHub for version control.
- Use AI-assisted tools responsibly during development.
- Test and document the AI Agent.

## Technologies Used

- Python
- Visual Studio Code
- Git
- GitHub
- Markdown

## How the Agent Works

The agent takes input from the user and checks for specific keywords.

Examples:

| User Input | Agent Response |
|---|---|
| hello | Greeting message |
| python | Information about Python and AI |
| study | Study advice |
| bye | Goodbye message |

If the agent does not recognize the input, it provides a default response.
