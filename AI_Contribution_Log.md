## Purpose

This document records how AI tools were used during the development of the Basic AI Agent project.

## AI Tools Used

### ChatGPT

ChatGPT was used as an AI-assisted learning and development tool.

The assistance included:

- Understanding the requirements of the project.
- Explaining Git and GitHub concepts.
- Providing step-by-step guidance for setting up the project.
- Explaining Python virtual environments.
- Suggesting the initial project structure.
- Generating and explaining the basic rule-based AI Agent code.
- Helping create project documentation.
- Helping identify and fix the incorrect `agent..py` filename.
- Suggesting testing steps for the AI Agent.
- Helping prepare the README and ADR documentation.

### GitHub Copilot

GitHub Copilot was installed as an AI-assisted coding tool.

It may be used during later development for code suggestions and assistance. Any significant code generated or modified using Copilot will be reviewed and documented.
